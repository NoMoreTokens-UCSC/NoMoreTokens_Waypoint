# Source provenance

Authoritative file: [Waypoint copy](https://www.figma.com/design/vIKm5ObsKXbTdEouHUk0iG/Waypoint?node-id=5-3).

Local REST exports of Connected Journeys (`5:3`) and Degradation (`425:3`) supply the layer properties and prototype references. Original user PNGs supply comparison baselines and static vector crops. User SVGs, logos and photos are preserved under `public/figma/originals`.

Figma MCP was used only for structure inspection. It supplied no generated code or implementation artwork. Starter-plan limits now prevent reading additional component-state targets.

DM Sans is bundled from the official Google Fonts repository with its SIL licence. The [official font description](https://github.com/google/fonts/blob/main/ofl/dmsans/DESCRIPTION.en_us.html) records its optical-size axis. Optical sizing was selected by comparison with the original screenshots.

Tokens remain outside browser code and Git. Scope/rationale labels and the original desktop reference group remain reference material.
