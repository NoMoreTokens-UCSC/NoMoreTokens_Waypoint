## Evidence and scope

- `responsive-audit.json`, `responsive-audit-360.json`, `responsive-audit-768.json`: every available inventory frame, including menus and drawers as overlays. Each report contains 272 scenes; deferred node `438:154` is excluded.
- Primary product routes cover 360, 390, 768, 834, 1024, 1280, 1440 and 1920 CSS pixels. These are distinct from the full-inventory sweeps at native, 360 and 768 widths.
- Tests cover short 600/700px screens and a 125% zoom-equivalent CSS viewport/display scale. Actual browser toolbar zoom and other browser engines remain manual checks.
- Geometry scans tolerate font leading, deliberate ellipsis and text contained inside its padded label component. They detect escaping text and overlapping flow siblings; intentional artwork/map layers require visual review.
- Source-backed visual differences are recorded in `product-pixel-comparisons.json`. Responsive layout checks passing is not a claim of exact pixel equality or verification of every prototype link.

## Motion

Scrollable fleet/order card lists keep horizontal wrapping and vertical scrolling. They are excluded from fallback panel stacking so all cards remain reachable at narrow tablet widths; the last fleet card is covered by the secondary-state regression check.

Home text/sections reveal with a 550ms eased slide and fade. The four steps slide from the left with 80ms staggering and reveal once. Popup panels enter with a 220ms slide and fade. Final positions, sizes, colors, images and typography are unchanged. Reduced-motion preferences show everything immediately, without sliding. Static reference and responsive fixtures do not animate their home sections; comparison tools request reduced motion. See `home-motion.md` for implementation and verification details.
